# 제휴 제안 메일 자동 발송 (토큰 없이 코드로만)

매일 한국시간 **오전 8시 50분**에 GitHub이 자동으로 실행해서(GitHub 예약이 가끔 건너뛰는 경우를 대비해 9:35, 10:35에도 예비 실행. 하루에 한 번만 보냄), 구글 시트의 대상 업체에게
**다음(Daum) 메일 서버로 1통에 1명씩** 제휴 제안 메일을 보냅니다.
Claude를 쓰지 않으니 토큰이 들지 않습니다.

## 어떻게 동작하나요?

```
구글 시트 ──(대상 목록)──▶ GitHub 자동 실행 ──(1통씩)──▶ 다음 메일 서버 ──▶ 각 업체
    ▲                          │
    └────(보낸 결과 기록)───────┘
```

1. 다음 메일함에서 **'수신거부' 회신**과 **반송 메일**을 찾아 시트의 `수신거부` 탭에 등록합니다. 이 주소들은 다시 보내지 않습니다.
2. 시트에서 오늘 보낼 대상을 고릅니다.
   - 세부업종이 "통신판매"이고 이메일이 있는 곳
   - 아직 안 보낸 곳 (`이메일 보냄` 칸 · `자동발송_로그` 탭 · `수신거부` 탭으로 확인)
   - **마케팅 대행사 제외**: 이름에 마케팅·광고·애드·바이럴·에이전시·대행·브랜딩·퍼포먼스·홍보·미디어가 들어간 곳, 업종이 "대행사"인 업체와 이메일이나 이름이 같은 곳
3. 1통에 받는 사람 1명씩 보냅니다. 받는 사람에게는 자기 주소만 보입니다. 메일 사이에 4~8초씩 쉬어서 한꺼번에 몰리지 않게 합니다.
4. 10통마다 `자동발송_로그` 탭과 `발송기록` 탭에 기록합니다.
5. 끝나면 결과 보고 메일 1통을 보냅니다.

## 하루 발송 수

| 기간 | 하루 발송 수 |
|---|---|
| 첫 주 (11/30 월 ~ 12/4 금) | 150통 |
| 12/7(월)부터 | 500통 |

자동 발송은 **평일(월~금)에만** 합니다. 공휴일 등 쉬는 날은 `send.py`의 `OFF_DATES`에 날짜를 넣으면 됩니다.

바꾸고 싶으면 둘 중 하나를 하면 됩니다.
- GitHub → Settings → Secrets and variables → Actions → **Variables** 탭에서 `DAILY_LIMIT`에 숫자를 넣습니다. 이 값이 있으면 위 일정 대신 이 값을 씁니다.
- `send.py`의 `SCHEDULE`을 수정합니다.

## 처음 설정 (한 번만)

### 1단계 — 구글 시트에 코드 붙이기
1. "유어애즈 파트너 풀 (자동 동기화)" 시트를 엽니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 원래 있던 코드를 모두 지우고 [`apps_script.gs`](apps_script.gs) 내용을 전부 붙여넣은 뒤 💾 저장합니다.
4. 위쪽 함수 선택 칸에서 **`setup`**을 고르고 **▶ 실행**을 누릅니다.
   - 권한 요청이 뜨면 본인 계정을 선택하고 → "고급" → "(안전하지 않음)으로 이동" → 허용을 누릅니다.
5. 아래 **실행 로그**에 나온 `SHEET_API_TOKEN (...): xxxxxxxx` 값을 복사해 둡니다.
6. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 톱니바퀴 아이콘 → **웹 앱**을 선택합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해 둡니다.

### 2단계 — GitHub에 비밀값 등록
GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret**에서 아래 5개를 등록합니다.

| 이름 | 넣을 값 |
|---|---|
| `SHEET_API_URL` | 1단계에서 복사한 웹 앱 URL |
| `SHEET_API_TOKEN` | 1단계에서 복사한 토큰 |
| `SMTP_USER` | 다음 메일 접속 아이디 (`jeongji1228`) |
| `SMTP_PASS` | 다음 메일 **앱 비밀번호** |
| `REPORT_TO` | 결과 보고를 받을 이메일 주소 |

비밀값은 암호화돼서 저장되고, 저장한 뒤에는 누구도(본인도) 내용을 다시 볼 수 없습니다.

### 3단계 — 시험 실행
GitHub 저장소 → **Actions → "제휴 제안 메일 자동 발송" → Run workflow**를 누르고 mode를 고릅니다.
1. **`test`**: `REPORT_TO`로 실제와 똑같은 메일을 3통 보냅니다(매번 새로 접속해 다음 메일 서버가 바뀌어도 통과하는지 확인). 메일함에서 모양을 확인하세요.
2. **`dry-run`**: 메일은 보내지 않고, 오늘 대상이 몇 곳인지만 확인합니다.

둘 다 문제가 없으면 끝입니다. 다음 날 아침부터 자동으로 발송합니다.

## 자주 묻는 것

- **잠깐 멈추고 싶어요:** Actions → 이 워크플로 → 오른쪽 위 `···` → **Disable workflow**를 누릅니다. 다시 켤 때는 Enable을 누르면 됩니다.
- **오늘 바로 보내고 싶어요:** Run workflow에서 mode를 `send`로 골라 실행합니다. 이미 보낸 곳은 자동으로 건너뜁니다.
- **메일 내용을 바꾸고 싶어요:** `template.html`을 수정합니다. 서명 배너 그림은 `banner.png`입니다.
- **한도에 걸리면?** 다음 메일 서버가 한도·인증 오류를 내면 그날은 자동으로 멈춥니다. 못 보낸 곳은 기록하지 않으니 다음 날 다시 보냅니다.
- **보낸 메일이 다음 '보낸메일함'에 안 보여요:** 서버로 바로 보내기 때문에 보낸메일함에는 남지 않습니다. 보낸 내역은 시트의 `자동발송_로그` 탭에서 확인하세요.
- **공개 저장소인데 괜찮나요?** 비밀번호와 토큰은 GitHub 비밀값으로만 저장되고 코드에는 들어가지 않습니다. 실행 기록(로그)에도 받는 사람 주소나 업체명은 남기지 않고 개수만 남깁니다.
